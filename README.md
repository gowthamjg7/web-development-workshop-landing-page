# Web Development Workshop – Landing Page

A responsive landing page for a Web Development Workshop, built using HTML and CSS.

## Overview

This project recreates a workshop registration landing page with a clean layout, an illustrative banner and a registration form.

## Features

- Responsive layout using CSS Media Queries
- Flexbox-based positioning
- Registration form UI
- Font Awesome icons
- Custom typography using Google Fonts
- Styled input fields and buttons
- Desktop and mobile-friendly layouts

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Media Queries
- Font Awesome
- Google Fonts
